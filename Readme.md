# ♟️ ChessMaster — Professional Web Chess Game

A modern, professional-looking chess game built completely with **HTML, CSS, and vanilla JavaScript**.

No frameworks, libraries, or backend are required.

---

## 🎮 Features

### ♟️ Chess Gameplay

- Complete 8×8 chess board
- Two-player local gameplay
- White vs Black
- Legal piece movement
- Pawn movement
- Pawn double-step on first move
- Pawn diagonal captures
- Rook movement
- Bishop movement
- Knight movement
- Queen movement
- King movement
- Capture pieces
- Turn-based gameplay

### 🧠 Game Logic

- Legal move validation
- Check detection
- Checkmate detection
- Stalemate detection
- King safety validation
- Prevents illegal moves
- Captured pieces tracking
- Move history
- Current turn indicator

### ♜ Special Chess Moves

- Castling
- Pawn promotion
- En passant
- Check indication
- Checkmate detection

### 🎨 UI / UX

- Professional chess interface
- Responsive design
- Modern dark theme
- Elegant chess board
- Selected-square highlighting
- Legal-move highlighting
- Capture-move highlighting
- Last-move highlighting
- Check highlighting
- Smooth animations
- Hover effects
- Responsive layout

### ⚙️ Game Controls

- New Game
- Restart Game
- Undo Move
- Flip Board
- Resign
- Move history
- Game status display

### 📱 Responsive

The game works on:

- 💻 Desktop
- 💻 Laptop
- 📱 Mobile
- 📱 Tablet
